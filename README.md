# Ticker Medical Inc. website

Static, single-page website prepared for GitHub Pages. The site uses only HTML and CSS, so it needs no build step or paid hosting service.

## Preview locally

Open `index.html` in a browser, or run `python -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Publish with GitHub Pages

1. While signed into GitHub, create a **public** repository named `ticker-medical-site` with a README.
2. Open the repository's **Add file → Upload files** page. Unzip the supplied package, then select `index.html`, `styles.css`, `favicon.svg`, and `README.md` and commit them to the default branch. Upload the files themselves, not their enclosing folder or the ZIP.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
4. GitHub will show the public URL in Pages settings. It will normally be `https://<your-username>.github.io/ticker-medical-site/`. A custom domain can be added later.
